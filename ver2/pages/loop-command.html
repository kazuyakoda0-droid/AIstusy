SESSION 07 · 実践・道具立て

/loop は、同じ作業をくり返させるコマンド

Do this. Again. And again.

仕事には「1回やって終わり」ではないものがあります。定期的な確認、監視、締め切り前のチェック。

そういう気にし続ける仕事を、そのままAIに預けるのが /loop です。

ひとことで言うと

/loop は「この作業を、決めた間隔でくり返して」と頼むコマンド。人が気にし続けなくてよくなります。

How

使い方

# 間隔を決めて回す ＄ /loop 5m テスト結果を確認して、失敗があれば原因を報告して → 5分ごとにこの作業をくり返します。 # 間隔を指定しないと、AIが自分でペースを決める ＄ /loop 新しい問い合わせメールが来ていないか見て、 緊急のものがあれば要約して知らせて → 状況に応じて自分で間隔を決めながら、くり返します。

間隔を指定すれば、その通りに。指定しなければ、AIが状況を見てペースを決めます（変化が速いものは短く、そうでないものは長く）。

たとえるなら

「気にしておいて」と頼める後輩。ずっと画面に張りついて見ている必要がなくなります。

Use cases

効く場面

CASE 1
待ちが発生する作業の見張り
時間のかかる処理が終わったか、定期的に確認して報告させる。人は別の仕事をしていられます。
CASE 2
定期チェック
「毎朝、前日の数字を集計して差分を報告」。日次・週次のルーチンをまるごと任せられます。
CASE 3
受信箱の見張り
新しく届いたものを拾って、緊急度で仕分けして知らせる。
CASE 4
長い作業の分割実行
一度に終わらない量の処理を、少しずつ進めさせる。

With goal

/goal と組み合わせると強い

この2つは、性格が正反対です。/goal は「終わりを決める」、/loop は「終わらせない」。組み合わせると、業務の形にぴったりはまります。

＄ /goal 今日届いた請求書を全部処理して、差額があるものを報告する → 今日ぶんを完走させる（終わりが決まっている仕事） ＄ /loop 30m 新しい請求書が届いていないか確認して、同じ処理をする → 明日も明後日も回り続ける（終わらない仕事）
止めるとき

くり返しは、こちらから止めるまで続きます。不要になったら必ず止めてください。始めるより、止め忘れないことのほうが大事です。

Caution

気をつけること

間隔を短くしすぎないでください。1分ごとに回しても、たいていは何も変わっていません。「その状況が実際にどれくらいで変わるか」に合わせるのがコツです。

そして /goal と同じく、くり返しの中に「送る」「消す」を入れないこと。1回の事故が、繰り返しぶん増えてしまいます。
