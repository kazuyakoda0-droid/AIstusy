# ねこ写真の置き場所

このフォルダに、下記の3ファイルを置いてください。
ファイル名は**このとおり**にしてください（CSSから参照しています）。

| ファイル名 | 使う写真 | 使われる場所 |
|---|---|---|
| `cat-kitten.jpg` | 首をかしげたグレーの子ねこ（大きな目） | 案内役ねこ。各回の「ひとことで言うと」ふきだし、フッター、詳細ページの帯 |
| `cat-silver.jpg` | こちらを見ているシルバータビー | トップのヒーロー、ヘッダーのロゴ横、詳細ページの「たとえるなら」ボックス |
| `cat-duo.jpg` | 並んでいる2匹の子ねこ（横長） | 第3章と第4章のあいだの写真バンド |

## 仕様

- **形式**: `.jpg`（`.png` を使う場合は `styles/base.css` と `styles/site.css` の
  `url(../img/…)` の拡張子も合わせて変更してください）
- **推奨サイズ**:
  - `cat-kitten.jpg` / `cat-silver.jpg` … 正方形に近いもの。短辺 600px 以上あれば十分
  - `cat-duo.jpg` … 横長。幅 1400px 以上あるときれい
- **顔の位置**: 丸く切り抜いて使うので、顔が中央寄りだときれいに収まります。
  ずれる場合は `styles/base.css` の `.catpic-kitten` / `.catpic-silver` の
  `background-position` を調整してください（例: `54% 38%` → `50% 30%`）。

## 写真が無いときの挙動

CSSの多重背景にしてあるため、**ファイルが無くてもページは壊れません**。
写真が読めない場合は、下敷きにしてある線画のねこが表示されます。
ファイルを置いて push すれば、そのまま写真に切り替わります。

## なじませ方（実装済み）

- 丸く切り抜き、サイト共通のヘアラインと同じ細いリングを1px
- 写真の上に暖色を7%だけ重ねて、紙の色（#F7F6F4）となじませている
- ヒーローの写真は、円の縁を放射グラデーションでぼかして背景に溶かしている
- 章あいだの写真バンドは、左右と上下を背景色にフェードさせて埋め込んでいる
