# ねこ写真

## ファイル構成

```
img/
  cat-kitten.jpg   480x480  案内役ねこ。各回の「ひとことで言うと」ふきだし、フッター、詳細ページの帯
  cat-silver.jpg   480x480  トップのヒーロー、ヘッダーのロゴ横、詳細ページの「たとえるなら」ボックス
  cat-duo.jpg      684x372  第3章と第4章のあいだの写真バンド
  _src/            元画像（PNG）。切り抜きのやり直しはここから
```

## 切り抜きのやり直し

顔の位置がずれた／もっと寄せたい・引きたいときは、
[`build/crop-photos.py`](../build/crop-photos.py) の `HEADS` を直して流し直します。

```bash
python build/crop-photos.py
```

`HEADS` の値は `(left, top, right, bottom, frac)`。

- 前の4つ … 元画像における**耳を含む頭部の範囲**（ピクセル）
- `frac` … 正方形の中で頭部が占める割合。**下げると引き、上げると寄り**
  - 耳が円からはみ出すときは `frac` を下げる
  - 顔が小さくて何のねこか分からないときは `frac` を上げる

正方形に足りない部分は、同じ写真をぼかしたもので埋めて、
縁を羽根ぼかしでなじませています（継ぎ目が出ません）。

## なじませ方（CSS側で実装済み）

- 丸く切り抜き、サイト共通のヘアラインと同じ細いリングを1px
- 写真の上に暖色を7%重ねて、紙の色（`#F7F6F4`）となじませている
  → `styles/base.css` の `.catpic::after`
- ヒーローの写真は、円の縁を放射グラデーションでぼかして背景に溶かしている
  → `styles/site.css` の `.hero-cat`
- 写真バンドは、上下左右をセクション背景色にフェードさせて紙に沈ませている
  → `styles/site.css` の `.pb-img::after`

## 写真が無いときの挙動

CSSの多重背景にしてあるため、**ファイルが無くてもページは壊れません**。
写真が読めない場合は、下敷きにしてある線画のねこが表示されます。
